# KTB4_gourmet_Week1
# 음료수 자판기 CLI 프로그램

## 과제 설명

콘솔에서 실행되는 음료수 자판기 프로그램입니다.

사용자는 원하는 음료를 선택하고 금액을 투입합니다.  
프로그램은 선택한 음료의 가격을 기준으로 거스름돈을 계산하고, 정해진 화폐 단위 순서대로 반환합니다.

## 프로그램 흐름

1. 원하는 음료수 번호를 선택한다.
2. 금액을 투입한다.
3. 선택한 음료의 가격을 차감한다.
4. 거스름돈을 계산한다.
5. 거스름돈을 50000원권, 10000원권, 5000원권, 1000원권, 500원, 100원 순서로 출력한다.
6. 이용 감사 메시지를 출력하고 프로그램을 종료한다.

## 메뉴 정보

| 번호 | 음료수 | 가격 |
|---|---|---:|
| 1 | 콜라 | 1000원 |
| 2 | 사이다 | 1500원 |
| 3 | 환타 | 2000원 |
| 4 | 커피 | 2500원 |
| 5 | 이온음료 | 3000원 |

## 클래스 설계

프로그램은 다음 클래스로 구성했습니다.

| 클래스 | 역할 |
|---|---|
| Product | 상품의 공통 정보인 이름과 가격을 관리 |
| Drink | Product를 상속받아 음료의 용량 정보를 관리 |
| Soda | Drink를 상속받아 실제 자판기 음료 정보를 출력 |
| VendingMachine | 자판기 실행 흐름 관리 |
| ChangeCalculator | 거스름돈 계산 및 출력 |
| Main | 프로그램 실행 시작점 |

## 상속 구조

이 프로그램은 2차 상속 구조를 사용했습니다.
